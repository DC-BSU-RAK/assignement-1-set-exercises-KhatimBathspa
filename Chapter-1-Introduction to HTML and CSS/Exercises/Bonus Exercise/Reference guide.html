HTML & CSS Quick-Reference Guide

Complete guide to web development essentials.

Basic HTML Tags We Learned

<h1> to <h6> - Headings

Used to define headings, from largest (<h1>) to smallest (<h6>).

<h1>Main Heading</h1>
<h2>Subheading</h2>

<p> - Paragraph

Defines a block of text.

<p>This is a paragraph.</p>

<a> - Anchor (Link)

Creates a hyperlink to another page or section.

<a href="https://example.com">Visit Site</a>

<img> - Image

Displays an image on the page.

<img src="image.jpg" alt="Description" />

<ul>, <li> - Lists

Unordered and ordered lists with list items.

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

Advanced HTML Tags

<section> & <article>

Structural elements for organizing related content.

<section>
  <article>
    <h2>News Article</h2>
    <p>Some news content here...</p>
  </article>
</section>

<nav> - Navigation

Contains main navigation links.

<nav>
  <a href="#home">Home</a>
  <a href="#about">About</a>
</nav>

<form> & <input>

Used to gather user input.

<form>
  <label>Name:</label>
  <input type="text" name="name" />
</form>

CSS Properties

1. color & background-color

p {
  color: #333;
  background-color: #f2f2f2;
}

2. font-family & font-size

h1 {
  font-family: "Segoe UI", sans-serif;
  font-size: 2.5rem;
}

3. margin & padding

section {
  margin: 20px 0;
  padding: 15px;
}

4. border & box-shadow

pre {
  border: 1px solid #ccc;
  box-shadow: 2px 2px 5px rgba(0,0,0,0.1);
}
